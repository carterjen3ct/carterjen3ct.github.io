Pakistan 2022 Flood Accuracy Assessment

This project used Google Earth Engine to assess how accurately satellite-derived flood maps captured the actual 2022 Pakistan flood event — one of the worst flooding disasters in recent history. I wrote a JavaScript script in the GEE Code Editor to process Sentinel-1 SAR imagery, generate flood inundation masks, and run an accuracy assessment comparing the results to reference data. It was a good exercise in understanding both the power and limitations of remote sensing for disaster response.

Methods: SAR change detection, accuracy assessment, confusion matrix analysis, remote sensing

DFW Vehicle Emissions Exposure

For this project my team looked at how vehicle-related emissions are distributed across the Dallas-Fort Worth metro area and which communities are most exposed. We pulled in OSM road network data and TxDOT Annual Average Daily Traffic (AADT) counts, then used kernel density analysis and hex-cell mapping in R to build an emissions exposure surface across the region. From there we ran regression against census tract-level socioeconomic variables — income, race, and population density — to see whether higher-exposure areas track with lower-income or minority communities. Group project for GEOG 469 Urban Analytics.

Methods: Kernel density analysis, hexagonal grid mapping, spatial regression, census data integration
