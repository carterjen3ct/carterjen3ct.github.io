Eastern Kentucky Flood Analysis

For this project I analyzed the 2022 Eastern Kentucky flooding event using a combination of ArcGIS Pro and Google Earth Engine. I processed Sentinel-1 SAR satellite imagery to detect flood inundation extent across the region, then used ArcGIS Pro to build out the spatial analysis and map layouts. The goal was to understand where flooding was worst and how the landscape features contributed to it — stuff like elevation, land cover, and proximity to waterways.

Methods: SAR image processing, flood extent mapping, spatial overlay analysis, geodatabase management

ArcGIS Pro Google Earth Engine Sentinel-1 SAR Python

Pakistan 2022 Flood Accuracy Assessment

This project used Google Earth Engine to assess how accurately satellite-derived flood maps captured the actual 2022 Pakistan flood event — one of the worst flooding disasters in recent history. I wrote a JavaScript script in the GEE Code Editor to process Sentinel-1 SAR imagery, generate flood inundation masks, and run an accuracy assessment comparing the results to reference data. It was a good exercise in understanding both the power and limitations of remote sensing for disaster response.

Methods: SAR change detection, accuracy assessment, confusion matrix analysis, remote sensing

Google Earth Engine JavaScript Sentinel-1 SAR Remote Sensing
