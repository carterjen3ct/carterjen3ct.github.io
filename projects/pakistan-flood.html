Pakistan 2022 Flood Inundation Mapping

This project used Google Earth Engine to map and assess flood inundation from the 2022 Pakistan floods — one of the worst flooding disasters in recent history, affecting over 33 million people. I wrote a JavaScript script in the GEE Code Editor to process Sentinel-1 SAR (Synthetic Aperture Radar) imagery, generate flood inundation masks through SAR change detection, and run an accuracy assessment comparing the results to reference data using a confusion matrix. The interactive tool below lets you explore the flood extent across the affected regions. It was a good exercise in understanding both the power and limitations of remote sensing for real-world disaster response.

Methods: SAR change detection, flood inundation masking, accuracy assessment, confusion matrix analysis.
